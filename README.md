# ⏰ Digital Clock App

A modern and responsive Digital Clock built using **HTML, CSS, and JavaScript**. This project displays the current time in real-time and demonstrates the use of JavaScript's `Date` object, `setInterval()`, and DOM manipulation. The application evolved from a basic clock into a feature-rich dashboard through multiple versions.

## 🚀 Features

### Version 1 - Basic Digital Clock
- Live real-time clock
- Hours, minutes, and seconds
- Updates every second using `setInterval()`

### Version 2 - Enhanced Clock
- 12-hour & 24-hour time format
- AM / PM indicator
- Leading zero formatting
- Current day display
- Full date display (Day, Month, Year)

### Version 3 - Advanced Clock Dashboard
- 🌙 Light / Dark Mode
- ⏱ Stopwatch
- ⏳ Countdown Timer
- ⏰ Alarm Functionality
- 📱 Responsive Design
- 🎨 Clean and modern UI

> **Note:** Analog Clock functionality is planned for a future update.
